# Hyprland Configuration

GuNix OS default configuration for Hyprland.

## Installation

Copy these files to your Hyprland config directory:

```bash
cp -r hyprland/ ~/.config/hypr/
```

## Key Bindings

- `Super + Return` - Open terminal
- `Super + D` - Application launcher (wofi)
- `Super + Arrow Keys` - Move focus
- `Super + Shift + Arrow Keys` - Move window
- `Super + 1-5` - Switch workspace
- `Super + Shift + 1-5` - Move window to workspace
- `Super + Q` - Close window
- `Super + M` - Exit Hyprland

## Customization

Edit `hyprland.conf` to customize:
- Colors
- Keybindings
- Monitor settings
- Window animations
- Gap sizes

See [Hyprland Documentation](https://wiki.hyprland.org/) for more options.
