# Installation Guide

## Requirements

- Arch Linux ISO
- At least 4GB RAM
- 20GB disk space (recommended)

## Quick Start

1. Boot from Arch Linux ISO
2. Run the GuNix OS installer script:
```bash
curl -sSL https://raw.githubusercontent.com/ChicoGC/GuNix-OS/main/scripts/install.sh | bash
```

3. Follow the on-screen prompts
4. Choose your desktop environment (Hyprland or GNOME)
5. Reboot and enjoy!

## Manual Installation

For detailed manual installation steps, see [ARCH_INSTALL.md](ARCH_INSTALL.md).

## Troubleshooting

If you encounter issues during installation, please check the [Arch Wiki](https://wiki.archlinux.org/) first.
